# viewr 0.7.0

An accessibility and collage preview over v0.6.5. This release follows supported
operating-system contrast and text-size settings, and repairs the full-image
collage for large camera photos. It remains a local-only, unsigned preview.

## Accessibility

- With Appearance set to System, viewr follows Windows contrast themes, macOS
  Increase Contrast, and the Linux desktop portal's contrast setting. The
  high-contrast palettes have automated 7:1 text and control contrast checks.
- The interface follows Windows Text size and the GNOME text scaling factor
  where the desktop portal exposes it. Enlargement is capped by the available
  window space so the minimum 640 by 480 layout keeps its menus reachable.
  Image pixels and image zoom are unchanged.
- Menu shortcut hints now use the palette's tested secondary-text color.
  Windows UI Automation smoke tests cover the native tree, keyboard actions,
  and collage selection. Cross-platform builds, semantic tests, and rendered
  palette inspections supplement that check.

## Collage and large folders

- Up opens a transient group of up to 12 complete, aspect-preserving photos.
  Large sources receive bounded display images for the collage; opening a
  selected photo loads its full-resolution source. Two full decodes may run at
  once, and the current image plus retained collage display images share a
  640 MiB decoded-pixel budget. Temporary decode and GPU memory can exceed
  that retained budget.
- A loading collage preview can no longer replace the full-resolution image in
  single-photo view. The Windows keyboard smoke exercises twelve synthetic
  6000 by 4000 photos, group paging, Escape, Enter, and Down.
- Large-folder rating discovery avoids redundant pathname checks while keeping
  two header snapshots and final source-identity validation.

## Install and verify

The fixed-version installer commands and manual archive instructions are in the
[installation guide](../INSTALL.md). Each platform archive and installer script
has a SHA-256 sidecar and GitHub build-provenance attestation. Archives include a
per-file manifest. The application has no account, telemetry, background update
check, or HTTP client. Installer network access occurs only when you run an
installer.

## Preview limits

- The artifact-bound representative-hardware matrix carried from v0.6 and the
  Narrator, VoiceOver, and Orca acceptance rows remain incomplete. Automated
  checks and the Windows UI Automation smoke do not prove speech quality,
  mixed-DPI behavior, or usability on every supported host. The open rows and
  next actions remain in the [roadmap](../ROADMAP.md).
- The Windows network-storage identity fallback has not been exercised on a
  representative NAS or SMB share. The large-folder performance probe passed
  its hosted CI gate; one local Windows run stalled during rating discovery and
  a complete rerun passed, so that intermittent behavior remains under study.
- Windows archives are not Authenticode-signed. macOS archives are not Developer
  ID signed or notarized. Normal operating-system trust warnings may appear;
  do not disable platform security controls to launch viewr.
- Camera RAW, wide-gamut and HDR output, touch gestures, and clipboard image
  transfer remain outside this preview. JPEG is the supported rating-write
  format. Native language review of the bundled catalogs remains open.
