# viewr 0.7.6

A focused patch over [v0.7.5](v0.7.5.md) for transparent pixels, a local
decode proof, and removal of an installer-owned tree. The viewer remains
local-only and an unsigned preview.

## Changes

- Composite transparent pixels over the image background. Opaque images keep
  the straight sRGB texture path. Any alpha below 255 is composited in
  premultiplied linear light for display only. Checkerboard is the last
  View > Image Background choice, applies only under the image rectangle, and
  is forgotten when the session ends. Image Information shows
  `Transparency: yes` when the decoded image has any alpha below 255. Saved
  pixels and Save As stay unchanged.
- Image Information ends with the measured local decode time for a successful
  file open, rounded to 0.1 ms, and whether the sandboxed worker or the
  in-process decoder produced it. The line states that decoding used no
  network. A crop does not clear it. In-memory diagnostics do not show it.
- `viewr doctor` names the in-memory PNG decode self-test and that it used no
  network.
- The README hero names Windows, macOS, and Linux. Fast by design cites one
  measured `viewr benchmark` row and the command that produced it.
- `install.sh uninstall` and `install.ps1 -Uninstall` in this release remove
  an installer-owned viewr directory, the command or PATH entry that points at
  it, and the Linux launcher and icon or the Windows Start menu shortcut that
  opens it. A directory with any other file stays in place. File associations
  and photos are left unchanged. The already published v0.7.5 installer does
  not include that command. Its manual removal steps stay in the installation
  guide.
- Source and release builds use the pinned Rust 1.99.1 compiler. The yanked
  clipboard-win 5.4.1 dependency is replaced by 5.4.3.

## Install and verify

Fixed-version installer commands and manual verification are in the
[installation guide](../INSTALL.md). All four platform archives and installer
scripts have SHA-256 sidecars and GitHub build-provenance attestations. Each
archive contains a per-file manifest. The application has no account,
telemetry, analytics, activity history, normal-run logging, or update service.

## Preview limits

- Representative-hardware and Narrator, VoiceOver, and Orca acceptance rows
  remain uncollected. Automated checks do not prove usability on every host.
- Windows network-storage behavior has not been validated on a representative
  NAS or SMB share. The 50,000-image rating scan, OS contrast acceptance, and
  installer recovery matrix remain separate open evidence requirements.
- Windows executables are not Authenticode-signed. macOS executables are not
  Developer ID signed or notarized. Normal operating-system trust warnings may
  appear; do not disable platform security controls to launch viewr.
- Camera RAW, wide-gamut and HDR output, and touch gestures remain outside
  this preview. Copying the on-screen image is included. Opening an image from
  clipboard pixels is not. JPEG is the supported rating-write format. Native
  language review of the bundled catalogs remains open.
- The v0.8 acceptance work remains open. This patch removes an installer-owned
  tree. It does not complete clean install on macOS, macOS update, full
  file-association acceptance, provenance beyond the existing release-workflow
  check, or the repeated 50,000-file rating probe. A hardware screenshot, a
  captured collage upload, and an animated transparent frame were not
  collected.
