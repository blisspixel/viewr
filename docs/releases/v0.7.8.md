# viewr 0.7.8

A focused patch over [v0.7.7](v0.7.7.md) for missing-format opens, damaged
WebP and TIFF files, the version command, benchmark path errors, stable
folder order, AppleDouble sidecars, and the installer-script explanation.
The viewer remains local-only and an unsigned preview.

## Changes

- Folder order no longer follows the order a directory was read. The same
  number with fewer digits stays first, so `img2` comes before `img02` and
  before `img10` when modification times match. Names that differ only by
  case stay adjacent in byte order.
- Folder scans and `viewr benchmark` skip AppleDouble sidecar files whose
  names start with `._`. Those files are metadata copied beside a photo.
  Opening one by an explicit path still attempts to decode it.
- A failed open names AVIF, HEIC, and camera RAW and does not offer Retry.
  The worker error carries a stable format token, so a reworded detail stays
  classified. Camera RAW remains deferred.
- Truncated WebP and TIFF files report that the file is damaged or incomplete,
  the same sentence truncated JPEG, PNG, and GIF already use.
- `viewr version --help` and `viewr help version` print help for that command.
  `viewr version` with an extra argument exits 2. `--version` and `-V` still
  print the version.
- `viewr benchmark` reports a missing directory and a file as different
  errors, includes the path as typed, and prints no table header until the
  path is a directory.
- The install command downloads one immutable installer script. That script
  installs the newest stable release unless a version is set. README, the
  installation guide, and `viewr update` say so.
- Linux accessibility and D-Bus use async-executor 1.14.1. Version 1.14.0 was
  yanked because a waker could use memory after the executor was dropped.

## Install and verify

Fixed-version installer commands and manual verification are in the
[installation guide](../INSTALL.md). All four platform archives and installer
scripts have SHA-256 sidecars and GitHub build-provenance attestations. Each
archive contains a per-file manifest. The application has no account,
telemetry, analytics, activity history, normal-run logging, or update service.

## Preview limits

- Representative-hardware and Narrator, VoiceOver, and Orca acceptance rows
  remain uncollected. Automated checks do not prove usability on every host.
- Windows network-storage behavior has not been validated on a representative
  NAS or SMB share. The 50,000-image rating scan, OS contrast acceptance, and
  installer recovery matrix remain separate open evidence requirements.
- Windows executables are not Authenticode-signed. macOS executables are not
  Developer ID signed or notarized. Normal operating-system trust warnings may
  appear; do not disable platform security controls to launch viewr.
- Camera RAW, wide-gamut and HDR output, and touch gestures remain outside
  this preview. Copying the on-screen image is included. Opening an image from
  clipboard pixels is not. JPEG is the supported rating-write format. Native
  language review of the bundled catalogs remains open.
- The v0.8 acceptance work remains open. This patch does not complete clean
  install on macOS, macOS update, full file-association acceptance, provenance
  beyond the existing release-workflow check, or the repeated 50,000-file
  rating probe.
