# viewr 0.7.5

A focused patch over [v0.7.4](v0.7.4.md) for copying the image on screen,
plain-language open failures, doctor output, and Windows path spelling. The
viewer remains local-only and an unsigned preview.

## Changes

- Copy the image on screen from the right-click menu, Edit > Copy, or
  Ctrl/Cmd+C. The copy includes unsaved rotation, flips, an applied crop, and
  Spot Heal. An image larger than 33554432 pixels is refused before a
  transformed copy is allocated. A text field keeps Ctrl/Cmd+C for its own
  selection.
- A failed open explains itself in one short sentence. A damaged, unsupported,
  or oversized file does not offer Retry. Permission, a missing file, a missing
  viewr-decode helper, and an unrecognized failure still do. Image Information
  keeps the decoder's own line. `viewr benchmark` prints the same sentence for
  a skipped file, and `--verbose` adds the decoder line.
- On Windows, a file dialog and a folder listing that differ only in
  capitalization are the same file. The catalog keeps the rating, Trash and a
  folder refresh cannot bring that file back under the other spelling, and the
  session adopts the listing's spelling. Other platforms stay case-sensitive.
- `viewr doctor` colors status tags by role on a terminal and keeps piped
  output, `NO_COLOR`, and `TERM=dumb` plain. Rows and help wrap to the terminal
  width. A failed report counts critical checks and warnings.
- A same-length in-place rewrite is rejected when the filesystem leaves the
  change time unchanged. Accepted sources keep an in-memory SHA-256 witness on
  every platform and fail closed before a rating or metadata write. The digest
  is not stored or logged.
- The Linux window identity is `io.github.blisspixel.viewr` on Wayland and X11,
  matching the desktop entry and icon. Installer upgrades remove the previous
  launcher and icon. An explicit rollback keeps the selected archive's identity.
- Top-bar notices can wrap onto two lines within the existing bar height.
  Longer messages keep a complete hover tooltip.

## Install and verify

Fixed-version installer commands and manual verification are in the
[installation guide](../INSTALL.md). All four platform archives and installer
scripts have SHA-256 sidecars and GitHub build-provenance attestations. Each
archive contains a per-file manifest. The application has no account,
telemetry, analytics, activity history, normal-run logging, or update service.

## Preview limits

- Representative-hardware and Narrator, VoiceOver, and Orca acceptance rows
  remain uncollected. Automated checks do not prove usability on every host.
- Windows network-storage behavior has not been validated on a representative
  NAS or SMB share. The 50,000-image rating scan, OS contrast acceptance, and
  installer recovery matrix remain separate open evidence requirements.
- Windows executables are not Authenticode-signed. macOS executables are not
  Developer ID signed or notarized. Normal operating-system trust warnings may
  appear; do not disable platform security controls to launch viewr.
- Camera RAW, wide-gamut and HDR output, and touch gestures remain outside
  this preview. Copying the on-screen image is included. Opening an image from
  clipboard pixels is not. JPEG is the supported rating-write format. Native
  language review of the bundled catalogs remains open.
- The v0.8 install, update, uninstall, association, and provenance acceptance
  work remains open. This patch does not claim completion of that milestone.
