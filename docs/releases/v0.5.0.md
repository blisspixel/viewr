# viewr 0.5.0

The format-contract preview. Multi-page TIFF and multi-size ICO expose bounded,
identifiable navigation without auto-play. The format table distinguishes
decode, animation, page, metadata, and color behavior. Camera RAW is
explicitly deferred from 1.0.

This closes the **v0.5.0** exit criteria. The **v0.6.0** product-quality
milestone is the next gate and remains open.

## Format contract

- **TIFF pages are first-class.** A multi-page document decodes off the UI
  thread under the same frame-count and decoded-byte ceilings as animation.
  Identity is Page N of M. Documents never auto-play. `[` and `]` plus Image
  Information and View step one page without wrapping. Pages may differ in
  size; a size change refits.
- **ICO frames keep directory order.** Identity is Icon N of M plus pixel size.
  The first presented still remains the largest size already shown, then
  stepping reaches the other directory entries. Documents never auto-play.
- **Edits are not destroyed by a page change.** In-progress crop or Spot Heal
  refuses `[` / `]` with a visible reason. A still container, or a decode that
  cannot read every page, keeps the first still image.
- **Animated GIF, WebP, and APNG** keep timed playback and gain the same
  previous/next step while paused. Frame identity remains Frame N of M.
- **The format table is honest by column.** Decode, animation, pages, metadata,
  and color are separate claims. Listing TIFF or ICO as supported no longer
  implies a single decoded image.
- **Camera RAW is deferred from 1.0.** Listed `.cr2`, `.nef`, `.arw`, `.dng`,
  `.rw2`, `.orf`, and `.raf` extensions still produce a documented worker
  error. The reserved `raw` feature does not decode. A later isolated-worker
  backend would still need orientation, color metadata, representative
  fixtures, fuzz seeds, and the same memory and deadline contracts as AVIF and
  HEIC.

## Install and verify

Download the archive for your platform or use the fixed-version installer
command in the [installation guide](../INSTALL.md). Every archive and installer
script has a SHA-256 sidecar and a GitHub build-provenance attestation. Archives
also contain a canonical per-file manifest.

The application itself has no network client. Installer scripts are separate,
foreground tools that contact only the official GitHub repository after you run
them. Updates are manual and explicit.

On Linux, a desktop session needs `libxkbcommon` plus either the X11 keyboard
and Xlib libraries or `libwayland-client`, and one usable graphics runtime:
`libEGL.so.1` for OpenGL, including Mesa software rendering, or `libvulkan.so.1`
with a driver installed behind it. `viewr doctor` reports exactly which of these
are missing and what to install. The Linux Open With chooser needs a session
bus and `xdg-desktop-portal`.

## Preview limits

These portable archives are not Authenticode-signed on Windows or notarized on
macOS. Normal operating-system trust warnings may appear. Do not disable
platform security controls to force a launch.

Reaching this milestone does not shorten the remaining 1.0 gates: product
quality on representative hardware, code signing and notarization, and human
Narrator, VoiceOver, and Orca acceptance. Wide-gamut preservation and HDR
presentation stay off. Release builds still do not claim general recovery from
an in-process thread panic. Optional AVIF, HEIC, and RAW decoders are not
enabled in these default archives. Camera RAW remains deferred from 1.0.
