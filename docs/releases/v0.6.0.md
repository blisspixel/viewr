# viewr 0.6.0

v0.6.0 is the integrated product-quality beta. These reviewed notes describe
the candidate scope. Their presence in the source tree is not publication
evidence. The release may be tagged only after the artifact-bound Windows,
macOS, and Linux product-quality matrix passes for one candidate workflow run.

## Product quality

- JPEG ratings write on Windows, macOS, and Linux for ordinary identity-bound
  files. Unix sources with extra hard links stay read-only.
- Help and first-run guidance now share the covered shortcut catalog. About
  includes page and frame navigation, reload, panels, fit, fullscreen, Escape,
  Save As, and Trash Undo, and its Close control remains reachable at the
  minimum window size.
- The first-run card names Open File, Open Folder, and drop in one spoken
  sentence. A failed first open keeps a short unprefixed error, Retry, and
  usable menus.
- Fullscreen hides persistent chrome so the photo uses the whole window. Escape
  closes a context menu, then cancels crop, then leaves Spot Heal, then exits
  fullscreen. Space tap fits without clearing rotation, flip, or crop. Folder
  browsing continues while a replacement decode is in flight. File decode uses
  extra cores (`logical CPUs minus one`, two through six) without growing the
  neighbor cache. Folder rating discovery uses the same cap. An empty rating
  filter recovers with Escape or folder-navigation keys. Spot Heal keyboard and
  pointer entry points share the same load-state blockers. Undo and Redo remain
  available while the idle Spot Heal tool is open, while active strokes and
  Refresh Source are mutually exclusive, and Refresh Source requires a distinct
  alternate patch. Discrete keyboard commands, including Escape, run once per
  press; auto-repeat remains available for continuous navigation, Crop nudging,
  page or frame stepping, and zoom. A widget menu consumes Escape before the
  active tool or fullscreen. Menu, filmstrip, and accessible-control
  enabled states match the same exclusive-work preflight as keyboard commands.
  Rotate and flip remain available during an idle Crop selection and preserve its
  geometry, while a live drag remains exclusive. Tool changes wait for folder and
  source-verification work. Rating writes wait for folder rating discovery so a
  stale scan result cannot replace a committed value in memory. Explicit browsing
  cancels superseded Open With verification before its chooser can appear.
- The release candidate gate binds all platform observations to checksummed
  archives and deterministic synthetic fixtures from one successful manual
  workflow run. It rejects the wrong release version, missing rows, generic
  observations, nonrepresentative platform metadata, incomplete numeric
  performance results, mixed provenance, changed bytes, failures, and critical
  or high-severity exceptions. The gate freshly downloads the recorded workflow
  run, canonically verifies all four archives, and binds every required session
  report to the archived executable instead of trusting caller-populated files.
  Retained manual candidate artifacts use uncompressed ZIPs so size limits apply
  before extraction as well as after download.
- The performance harness can retain a path-free JSON report bound to the tested
  candidate executable pair, with raw runs, exact folder growth, sanitized
  renderer controls, the actual wgpu adapter used to present frames, and a
  non-overwriting session identity. Its summary and budgets use the slower
  small-folder or large-folder median for window and first-pixel timing, plus the
  worst navigation and idle redraw result across every retained run. It runs
  private copies and rejects byte or adapter changes. The CI software-GL probe and
  the Linux Mesa session both require viewr itself to use an identified OpenGL
  software renderer. Direct tests cover APNG and animated WebP through viewr's
  playback path, animation control semantics, stable status-card geometry, and
  complete About modal behavior.

## Maintenance

- The optional HEIC decoder dependency and its Flatpak source map are current.
- Release automation uses reviewed immutable action revisions and retains a
  separate synthetic fixture artifact for product-quality testing without
  adding it to the public release asset set.

## Preview limits

- Archives remain unsigned. Windows may show an unknown-publisher warning, and
  macOS builds are not Developer ID signed or notarized. Do not disable platform
  security controls to launch viewr.
- Camera RAW remains explicitly deferred. Rating writes remain limited to
  ordinary supported JPEG files. Unix sources with extra hard links stay
  read-only. Wide-gamut and HDR output, touch gestures, and clipboard image
  transfer remain outside this milestone.
- viewr remains local-only, with no account, telemetry, advertising, cloud
  library, background update check, or application HTTP client.
