# viewr 0.6.0

The integrated product-quality beta. Fullscreen is immersive, a transient
full-image collage shows folder context without becoming a catalog, a folder
sibling that disappears before presentation recovers deterministically, and
discrete keyboard commands run once per press.

This release ships the v0.6.0 product scope with one explicit evidence
exception recorded under [Preview limits](#preview-limits). The **v0.7.0**
human accessibility evidence milestone is the next gate and remains open.

## Product quality

- JPEG ratings write on Windows, macOS, and Linux for ordinary identity-bound
  files. Unix sources with extra hard links stay read-only.
- Help and first-run guidance now share the covered shortcut catalog. About
  includes page and frame navigation, reload, panels, fit, fullscreen, Escape,
  Save As, and Trash Undo, and its Close control remains reachable at the
  minimum window size.
- The first-run card names Open File, Open Folder, and drop in one spoken
  sentence. A failed first open keeps a short unprefixed error, Retry, and
  usable menus.
- Fullscreen hides persistent chrome so the photo uses the whole window. Escape
  closes a context menu, then cancels crop, then leaves Spot Heal, then leaves the
  full-image collage, then exits fullscreen. Space tap fits without clearing
  rotation, flip, or crop. Folder
  browsing continues while a replacement decode is in flight. File decode uses
  extra cores (`logical CPUs minus one`, two through six) without growing the
  neighbor cache. Folder rating discovery uses the same cap. An empty rating
  filter recovers with Escape or folder-navigation keys. Spot Heal keyboard and
  pointer entry points share the same load-state blockers. Undo and Redo remain
  available while the idle Spot Heal tool is open, while active strokes and
  Refresh Source are mutually exclusive, and Refresh Source requires a distinct
  alternate patch. Discrete keyboard commands, including Escape, run once per
  press; auto-repeat remains available for continuous navigation, Crop nudging,
  page or frame stepping, and zoom. A widget menu consumes Escape before the
  active tool or fullscreen. Menu, filmstrip, and accessible-control
  enabled states match the same exclusive-work preflight as keyboard commands.
  Rotate and flip remain available during an idle Crop selection and preserve its
  geometry, while a live drag remains exclusive. Save As requires that selection
  to be applied or canceled instead of silently exporting uncropped pixels. Tool
  changes, Spot Heal strokes, and heal-source refreshes wait for conflicting
  foreground work, and brush settings stay fixed during a collected stroke.
  Rating writes and source reloads wait for folder rating discovery so a stale
  scan result cannot replace a committed or reloaded value in memory. Explicit
  browsing cancels superseded Open With verification before its chooser can
  appear. First-write rating disclosure is bound to the selected and presented
  source, cancels across navigation or reload, repeats all foreground checks at
  confirmation, and exclusively owns the remaining actions collected in its
  opening frame.
- View > Full-Image Collage, Up, and `Shift+G` show up to 24 complete, uncropped
  photos from the active rating projection. Actual photo aspect ratios define
  dense justified rows with narrow gutters instead of equal blank cells. The mode
  uses full image decodes, output color normalization, and mipmaps rather than the
  Folder Previews thumbnail path. Left and Right select; Down, Enter, or click
  opens; Page Up and Page Down change groups; and Escape returns. Current plus
  neighbor decoded pixels remain inside 256 MiB; if the whole group cannot fit,
  fewer full photos reflow with an explicit status.
- A selected folder sibling that disappears before presentation is confirmed
  absent twice, removed from the playlist, and replaced deterministically by a
  surviving image. A fresh parent scan recovers when the installed list empties,
  and scan failures leave Retry available. Presented-file deletion remains under
  the existing last-good-frame watcher contract. Empty playlists no longer show
  an invented `1 / 1` selection or act like a clearable empty rating filter, and
  Retry retains folder recovery until the load reaches a settled outcome.
- A lost foreground decode result channel exits the loading state, retains any
  last good frame, and exposes a durable path-free Retry error.
- The release candidate gate binds all platform observations to checksummed
  archives and deterministic synthetic fixtures from one successful manual
  workflow run. It rejects the wrong release version, missing rows, generic
  observations, nonrepresentative platform metadata, incomplete numeric
  performance results, mixed provenance, changed bytes, failures, and critical
  or high-severity exceptions. The gate freshly downloads the recorded workflow
  run, canonically verifies all four archives, and binds every required session
  report to the archived executable instead of trusting caller-populated files.
  Retained manual candidate artifacts use uncompressed ZIPs so size limits apply
  before extraction as well as after download.
- The performance harness can retain a path-free JSON report bound to the tested
  candidate executable pair, with raw runs, exact folder growth, sanitized
  renderer controls, the actual wgpu adapter used to present frames, and a
  non-overwriting session identity. Its summary and budgets use the slower
  small-folder or large-folder median for window and first-pixel timing, plus the
  worst navigation and idle redraw result across every retained run. It runs
  private copies and rejects byte or adapter changes. The CI software-GL probe and
  the Linux Mesa session both require viewr itself to use an identified OpenGL
  software renderer. Direct tests cover APNG and animated WebP through viewr's
  playback path, animation control semantics, stable status-card geometry, and
  complete About modal behavior.

## Maintenance

- The optional HEIC decoder dependency and its Flatpak source map are current.
- Release automation uses reviewed immutable action revisions, including the
  supported Node.js 24 cache runtime, and retains a separate synthetic fixture
  artifact for product-quality testing without adding it to the public release

- The README and packaged documentation include current, bounded Dark and
  Console application captures with no desktop content or private path.

## Install and verify

Download the archive for your platform or use the fixed-version installer
command in the [installation guide](../INSTALL.md). Every archive and installer
script has a SHA-256 sidecar and a GitHub build-provenance attestation. Archives
also contain a canonical per-file manifest.

The application itself has no network client. Installer scripts are separate,
foreground tools that contact only the official GitHub repository after you run
them. Updates are manual and explicit.

## Preview limits

- **The representative-hardware product-quality matrix was not completed for
  this release.** [Product quality](../PRODUCT-QUALITY.md) defines a
  three-platform, artifact-bound acceptance matrix and an eight-session
  performance report set for v0.6.0. Those records were not collected, so no
  Windows, macOS, or Linux hardware row and no performance report exists under
  `docs/release-evidence/product-quality/v0.6.0`. This release was published on
  the automated gates alone: hosted multi-OS CI, fuzzing, coverage, dependency
  and advisory policy, privacy tripwires, sandbox profiles, and the deterministic
  archive contract. Treat startup, navigation, memory, mixed-DPI, multi-monitor,
  and profiled-display behavior on real hardware as unverified for this tag. The
  matrix remains open and is a prerequisite for v0.7.0.
- Archives remain unsigned. They are not Authenticode-signed on Windows, and
  macOS builds are not Developer ID signed or notarized. Normal operating-system
  trust warnings may appear. Do not disable platform
  security controls to launch viewr.
- Camera RAW remains explicitly deferred. Rating writes remain limited to
  ordinary supported JPEG files. Unix sources with extra hard links stay
  read-only. Wide-gamut and HDR output, touch gestures, and clipboard image
  transfer remain outside this milestone.
- viewr remains local-only, with no account, telemetry, advertising, cloud
  library, background update check, or application HTTP client.
