# viewr 0.7.1

A patch over [v0.7.0](v0.7.0.md) for folder rating scan performance and safer
installer recovery. The viewer remains a local-only, unsigned preview.

## Changes

- Folder rating discovery avoids a redundant pathname metadata read before its
  final no-follow open. It still requires a regular file, verifies native file
  identity and version, and compares two bounded header snapshots. Six synthetic
  50,000-file Windows runs passed the performance gate after this change; worker
  scan times ranged from 13.48 to 17.56 seconds. This does not establish a
  guarantee for every disk or network share.
- The explicit performance probe now measures the complete rating discovery
  path and reports where scan time is spent. It accepts an idle observation
  completed before the deadline even if its wake event is delivered later.
- On macOS and Linux, reinstalling the same version refuses to replace a
  managed directory containing extra files, links, or a changed ownership
  marker. If update activation and restoration both fail, the installer reports
  the retained backup location accurately.
- The Windows installer has an automated activation-failure rollback check.

## Install and verify

Fixed-version installer commands and manual archive instructions are in the
[installation guide](../INSTALL.md). The four platform archives and installer
scripts have SHA-256 sidecars and GitHub build-provenance attestations. Each
archive contains a per-file manifest. The application has no account,
telemetry, background update check, or HTTP client.

## Preview limits

- Representative-hardware and Narrator, VoiceOver, and Orca acceptance rows
  remain uncollected. Automated checks do not prove usability on every host.
- Windows network-storage identity behavior has not been validated on a
  representative NAS or SMB share.
- Windows executables are not Authenticode-signed. macOS executables are not
  Developer ID signed or notarized. Normal operating-system trust warnings may
  appear; do not disable platform security controls to launch viewr.
- Camera RAW, wide-gamut and HDR output, touch gestures, and clipboard image
  transfer remain outside this preview. JPEG is the supported rating-write
  format. Native language review of the bundled catalogs remains open.
