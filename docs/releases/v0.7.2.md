# viewr 0.7.2

A patch over [v0.7.1](v0.7.1.md) adding in-window path fallback for empty launch
and non-portal desktop environments. The viewer remains a local-only, unsigned
preview.

## Changes

- When native file-chooser dialogs do not present or fail to open in minimal
  desktop sessions, users can paste a file or folder path directly into the
  viewer using the new Paste Path button on the empty-state card, the File menu,
  or the standard primary-modifier shortcut (Ctrl+V on Windows/Linux, Cmd+V on
  macOS).
- Path input normalizes plain paths, quoted paths, and `file://` or `file:///`
  URIs. Valid paths open the target file with sibling navigation or select the
  target folder for the session. Empty clipboards or paths that do not exist
  produce clear, localized feedback without crashing or silent failure.
- The new control and status feedback are cataloged in English, Spanish,
  French, and German.

## Install and verify

Fixed-version installer commands and manual archive instructions are in the
[installation guide](../INSTALL.md). The four platform archives and installer
scripts have SHA-256 sidecars and GitHub build-provenance attestations. Each
archive contains a per-file manifest. The application has no account,
telemetry, background update check, or HTTP client.

## Preview limits

- Representative-hardware and Narrator, VoiceOver, and Orca acceptance rows
  remain uncollected. Automated checks do not prove usability on every host.
- Windows network-storage identity behavior has not been validated on a
  representative NAS or SMB share.
- Windows executables are not Authenticode-signed. macOS executables are not
  Developer ID signed or notarized. Normal operating-system trust warnings may
  appear; do not disable platform security controls to launch viewr.
- Camera RAW, wide-gamut and HDR output, touch gestures, and clipboard image
  pixel transfer remain outside this preview. JPEG is the supported rating-write
  format. Native language review of the bundled catalogs remains open.
