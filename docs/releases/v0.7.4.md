# viewr 0.7.4

A focused patch over [v0.7.3](v0.7.3.md) for Linux window loss, reliable image
entry, and small control fixes. The viewer remains local-only and an unsigned
preview.

## Changes

- Type or paste an image or folder path directly into the empty window or
  File > Open Path. Enter opens it; missing paths remain editable with wrapped
  feedback. This input is cleared after a successful request and never saved.
- Native Open File and Open Folder are parented to the viewer. Returning without
  a selection shows recovery guidance while empty or already viewing, without
  claiming that cancellation proves a portal failure.
- Destroying an X11 window while an unconfirmed rating disclosure is open exits
  cleanly. Frame geometry uses observed resize events, and software OpenGL
  uploads to the lost drawable follow the same close policy. Unconfirmed ratings
  remain unwritten; accepted rating, Save As, and Trash work finishes before exit.
- Failed file work after window loss reports a nonzero process error instead of
  an invisible toast. A queued Trash move that cannot start retains failure
  guidance on normal close, even when the preceding move succeeded.
- Unsupported rating formats no longer show a selected Unrated choice. TIFF
  page and ICO icon chevrons have larger hit targets without larger glyphs.
  Error-state filename and status text have proper spacing.
- CI exercises a real X11 window with a synthetic JPEG, observes the rating
  disclosure, and verifies clean shortcut and external-destruction exits with
  unchanged source bytes and empty stderr.

## Install and verify

Fixed-version installer commands and manual verification are in the
[installation guide](../INSTALL.md). All four platform archives and installer
scripts have SHA-256 sidecars and GitHub build-provenance attestations. Each
archive contains a per-file manifest. The application has no account,
telemetry, analytics, activity history, normal-run logging, or update service.

## Preview limits

- Native chooser presentation still depends on the host desktop and its portal.
  The typed path, clipboard path, drop, and command-line entry remain available
  without adding an application network client or persisting image paths.
- Representative-hardware and Narrator, VoiceOver, and Orca acceptance rows
  remain uncollected. Automated checks do not prove usability on every host.
- Windows network-storage behavior has not been validated on a representative
  NAS or SMB share. The 50,000-image rating scan, OS contrast acceptance, and
  installer recovery matrix remain separate open evidence requirements.
- Windows executables are not Authenticode-signed. macOS executables are not
  Developer ID signed or notarized. Normal operating-system trust warnings may
  appear; do not disable platform security controls to launch viewr.
- Camera RAW, wide-gamut and HDR output, touch gestures, and clipboard image
  pixel transfer remain outside this preview. JPEG is the supported rating-write
  format. Native language review of the bundled catalogs remains open.
- The v0.8 install, update, uninstall, association, and provenance acceptance
  work remains open. This patch does not claim completion of that milestone.
