# viewr 0.6.1

A shipped-feedback patch over the integrated v0.6.0 product-quality beta. This
release makes rapid folder curation responsive, clarifies editing and default-app
behavior, introduces an offline language preference, and keeps the image at the
center of the interface.

The representative-hardware evidence gap inherited from v0.6.0 remains explicit
under [Preview limits](#preview-limits). v0.7.0 remains the next minor milestone
and is reserved for completed accessibility evidence.

## Folder review and curation

- Folder browsing opens the most recently modified image first. File >
  Preferences and View > Folder Sort can persist natural filename order instead.
  viewr explains that Explorer, Finder, and Linux association launches provide a
  selected file but no portable representation of the file manager's current
  sort.
- Moving the visible image to Trash or confirming permanent delete begins
  presenting the surviving neighbor as soon as the background action is accepted.
- Repeated Delete presses accept each fully presented image into a bounded queue
  and advance immediately while one platform Trash worker drains the queue in
  order. Platform calls and exact receipt capture remain serialized. A selected
  image that is still loading is never queued and receives an explicit wait
  reason. Failure stops requests that never reached the platform and reports a
  path-free count.
- Routine results such as Moved to Trash use top chrome instead of covering the
  photo. Immersive fullscreen and Full-Image Collage retain a compact overlay
  because their persistent chrome is hidden.
- Full-Image Collage groups contain up to 12 complete, uncropped photos instead
  of 24, keeping each image useful while Page Up and Page Down continue through
  the folder.

## Editing and interface

- Spot Heal success now states that repaired pixels remain in memory and directs
  the user to Save As. A continuing top-chrome cue preserves that boundary, and a
  successful export confirms when the saved copy contains edited pixels.
- Rotate actions use directional arc arrows, horizontal and vertical flip use
  mirrored shapes around the changed axis, crop uses intersecting corner marks,
  and Spot Heal uses a bandage and repair spark. Accessible names and shortcuts
  remain explicit.
- File > Default Image Viewer provides an opt-in route for choosing viewr per
  file type on Windows, macOS, and Linux. Installation and startup never change
  associations automatically.
- File > Preferences follows the operating-system language by default and offers
  bundled offline English, Spanish, French, and German choices. Primary menus,
  preferences, entry actions, crop controls, and main panel headings change live.
  Advanced status, recovery, metadata, and editing explanations use documented
  English fallback until the complete catalog and native accessibility matrix are
  finished.

## Install and verify

Download the archive for your platform or use the fixed-version installer command
in the [installation guide](../INSTALL.md). Every archive and installer script
has a SHA-256 sidecar and a GitHub build-provenance attestation. Archives also
contain a canonical per-file manifest.

The application itself has no network client. Installer scripts are separate,
foreground tools that contact only the official GitHub repository after you run
them. Updates are manual and explicit.

## Preview limits

- **The representative-hardware product-quality matrix is still incomplete.**
  [Product quality](../PRODUCT-QUALITY.md) defines the three-platform,
  artifact-bound acceptance matrix and eight performance sessions carried from
  v0.6.0. No complete Windows, macOS, or Linux hardware row exists yet. This tag
  therefore ships on the automated gates without claiming verified startup,
  navigation, memory, mixed-DPI, multi-monitor, or profiled-display behavior on
  representative hardware. The matrix remains a prerequisite for v0.7.0.
- Archives remain unsigned. They are not Authenticode-signed on Windows, and
  macOS builds are not Developer ID signed or notarized. Normal operating-system
  trust warnings may appear. Do not disable platform security controls to launch
  viewr.
- Camera RAW remains deferred. Rating writes remain limited to ordinary supported
  JPEG files. Unix sources with extra hard links stay read-only. Wide-gamut and
  HDR output, touch gestures, and clipboard image transfer remain outside this
  release.
- viewr remains local-only, with no account, telemetry, advertising, cloud
  library, background update check, or application HTTP client.
