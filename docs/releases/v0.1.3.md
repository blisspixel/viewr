# viewr 0.1.3

A patch release over [v0.1.2](v0.1.2.md). It fixes the reason a session whose
only working renderer is software Mesa could never open a window, no matter
which packages were installed. No feature scope changed, and the privacy
boundary is unchanged.

The **v0.2.0** reliability milestone and its exit criteria remain open; this
patch does not close them.

## Fixed

- **viewr can present through OpenGL again.** The display connection is now
  handed to the graphics instance, which the OpenGL backend requires. Without
  it that backend selected a surfaceless platform, chose a configuration that
  cannot render to a native window, and then reported every window surface as
  incompatible. A host with no Vulkan driver saw `gl not compatible with
  provided surface` and no picture, even after installing every package
  `viewr doctor` named. Continuous integration now presents a frame on a virtual
  X session through the OpenGL backend, so this wiring cannot regress unnoticed.
- **A Vulkan loader with no driver behind it is no longer counted as a graphics
  runtime.** `libvulkan.so.1` is packaged separately from every driver, so a host
  can resolve it and still enumerate nothing. `viewr doctor` now reports that
  state as a loader without a driver, and a session in it fails with the EGL and
  driver packages named instead of being told, one package too early, that its
  display is at fault.

## Documentation

- The [installation guide](../INSTALL.md) states that the Vulkan loader ships
  separately from every driver, and how `viewr doctor` reports that state.

## Install and verify

Download the archive for your platform or use the fixed-version installer
command in the [installation guide](../INSTALL.md). Every archive and installer
script has a SHA-256 sidecar and a GitHub build-provenance attestation. Archives
also contain a canonical per-file manifest.

The application itself has no network client. Installer scripts are separate,
foreground tools that contact only the official GitHub repository after you run
them. Updates are manual and explicit.

On Linux, a desktop session needs `libxkbcommon` plus either the X11 keyboard
and Xlib libraries or `libwayland-client`, and one usable graphics runtime:
`libEGL.so.1` for OpenGL, including Mesa software rendering, or `libvulkan.so.1`
with a driver installed behind it. `viewr doctor` reports exactly which of these
are missing and what to install.

## Preview limits

These portable archives are not Authenticode-signed on Windows or notarized on
macOS. Normal operating-system trust warnings may appear. Do not disable
platform security controls to force a launch.

The remaining 1.0 gates are unchanged by this patch: code signing and
notarization, human Narrator, VoiceOver, and Orca acceptance,
representative-hardware checks, and per-display color correctness. Optional
AVIF, HEIC, and RAW decoders are not enabled in these default archives.
