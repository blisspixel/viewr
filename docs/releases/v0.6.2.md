# viewr 0.6.2

A shipped-feedback patch over v0.6.1. This release keeps folder culling
responsive, keeps collage Delete on the focused group, and extends the offline
English, Spanish, French, and German catalogs through first-run, About, Trash,
wait copy, rating failures, and chrome including accessible names.

The representative-hardware evidence gap inherited from v0.6.0 remains explicit
under [Preview limits](#preview-limits). v0.7.0 remains the next minor milestone
and is reserved for completed accessibility evidence.

## Folder review and collage

- Folder membership refresh keeps the open catalog, ratings, filter, Undo scope,
  and already-decoded neighbors instead of treating the folder as a new open.
  Sibling and membership scans no longer take the exclusive folder-scan lock, so
  Delete and navigation do not freeze behind a wait for the folder scan.
- Opening a file keeps a one-item catalog while siblings enumerate. Deleting that
  opened file before the sibling list arrives still installs the remaining files.
- Collage Delete of the photo you opened stays in the group. Shift+Delete
  permanently deletes the focused ready photo after confirmation, and U still
  restores. A failed move puts that photo back on the current collage page.

## Localization

- First-run, open-status, Retry, About shortcuts, Trash and restore copy,
  concurrent-work wait sentences, rating write failures, and dock, rating, and
  Undo Trash chrome including accessible names now follow the selected language.
- A missing catalog entry fails the build. Wait sentences are one frame per
  language rather than English word order. The attempted action is a typed value
  so an untranslatable English phrase cannot be passed in.
- Remaining image-information, preferences, and file-association copy still uses
  the documented English fallback. Native review of the catalog remains a gate
  before the v0.7 language row.

## Documentation and verification

- Hosted CI covers Windows, macOS, and Linux builds and tests. The release gate
  also enforces formatting, strict Clippy, Rust and Python coverage above 85
  percent, dependency and advisory policy, privacy checks, fuzzing, deterministic
  archive manifests, checksums, and GitHub build-provenance attestations.

## Install and verify

Download the archive for your platform or use the fixed-version installer command
in the [installation guide](../INSTALL.md). Every archive and installer script
has a SHA-256 sidecar and a GitHub build-provenance attestation. Archives also
contain a canonical per-file manifest.

The application itself has no network client. Installer scripts are separate,
foreground tools that contact only the official GitHub repository after you run
them. Updates are manual and explicit.

## Preview limits

- **The representative-hardware product-quality matrix is still incomplete.**
  [Product quality](../PRODUCT-QUALITY.md) defines the three-platform,
  artifact-bound acceptance matrix and eight performance sessions carried from
  v0.6.0. No complete Windows, macOS, or Linux hardware row exists yet. This tag
  therefore ships on the automated gates without claiming verified startup,
  navigation, memory, mixed-DPI, multi-monitor, or profiled-display behavior on
  representative hardware. The matrix remains a prerequisite for v0.7.0.
- Archives remain unsigned. They are not Authenticode-signed on Windows, and
  macOS builds are not Developer ID signed or notarized. Normal operating-system
  trust warnings may appear. Do not disable platform security controls to launch
  viewr.
- Camera RAW remains deferred. Rating writes remain limited to ordinary supported
  JPEG files. Unix sources with extra hard links stay read-only. Wide-gamut and
  HDR output, touch gestures, and clipboard image transfer remain outside this
  release.
- Native language review of the bundled catalogs is still open. Destructive-action
  copy and accessible names are translated, but they have not yet passed a native
  reader and assistive-technology matrix.
- viewr remains local-only, with no account, telemetry, advertising, cloud
  library, background update check, or application HTTP client.
