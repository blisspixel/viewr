# viewr 0.7.9

A focused patch over [v0.7.8](v0.7.8.md) for windowed Fit, full-image
collage density, a session rating advance and the Unrated filter, labelled
DNG and Sony ARW embedded previews, folder entry, JPEG rating times, the
shortcut list, rating notices, Windows Trash undo, and the Linux archive
glibc contract.
The viewer remains local-only and an unsigned preview. This patch is not
v0.8.0.

## Changes

- Windowed Fit fills the frame. A small photo enlarges until one axis
  reaches the available viewport, keeping its aspect ratio and the
  letterbox. View > Cap Fit at actual size restores the previous cap for
  this session and is not saved. Actual Size stays one source pixel per
  display pixel. Fullscreen Fit still fills.
- Full-image collage density steps with Up and Down. The first Up shows
  up to 4 photos around the selection, the next up to 9, then up to 12.
  Down steps back one level and then opens the focused photo. Page Up and
  Page Down move by the current level. Tiles stay aspect-justified, and
  the group still stays inside the existing memory budget.
- View > Advance after rating is off at launch and lasts for the session.
  After a rating is saved it opens the next photo in the active filter,
  including Unrated, and it does not wrap at the last photo. A failed
  write and the first-rating disclosure stay on the current photo. The
  filter also shows how many numeric ratings are already known. Unrated
  keeps rejected, conflicting, unsupported, unreadable, and still-loading
  photos out. Neither choice is saved.
- A DNG or Sony ARW file shows its largest decodable embedded baseline
  JPEG and labels that size as a preview. The sensor image is not
  decoded. Opening that preview does not say that container pages are
  unavailable. A DNG or ARW with no such preview, and every other camera
  RAW type, still says that viewr does not open camera RAW files yet.
- Opening a folder starts on the first photo viewr can show. A camera RAW
  file stays in the folder.
- Rating a JPEG puts that file's previous modification time back. Latest
  First keeps the photo in place.
- Help > Keyboard Shortcuts, `?`, and F1 open the same shortcut list as
  About. Escape, the Close button, or another key closes it.
- A saved or cleared rating message leaves the top bar when the visible
  photo changes. It still disappears after three seconds if the same photo
  stays on screen.
- Undo Trash on Windows restores a photo after Delete, including when the
  listing hides the file extension. The photo returns with its original
  name, and a JPEG rating stays in the file.
- Interface arrows stay drawable when the selected sans has no arrow
  glyphs. The bundled Hack face supplies those symbols.
- The window and controls use wgpu 30 and egui 0.37. Pictures stay on the
  historical sRGB surface.
- `url` 2.5.9 closes the nested `blob:` origin advisory.
- The Linux release job links the archive on Ubuntu 24.04 and refuses a
  recorded GLIBC floor above 2.39. That job measures this archive's floor.
  The published v0.7.8 archive was linked on Ubuntu 26.04 and needs glibc
  2.43. The installer names that requirement before downloading v0.7.8.

## Install and verify

Fixed-version installer commands and manual verification are in the
[installation guide](../INSTALL.md). All four platform archives and installer
scripts have SHA-256 sidecars and GitHub build-provenance attestations. Each
archive contains a per-file manifest. The application has no account,
telemetry, analytics, activity history, normal-run logging, or update service.

## Preview limits

- Representative-hardware and Narrator, VoiceOver, and Orca acceptance rows
  remain uncollected. Automated checks do not prove usability on every host.
- Windows network-storage behavior has not been validated on a representative
  NAS or SMB share. The 50,000-image rating scan, OS contrast acceptance, and
  installer recovery matrix remain separate open evidence requirements.
- Windows executables are not Authenticode-signed. macOS executables are not
  Developer ID signed or notarized. Normal operating-system trust warnings may
  appear; do not disable platform security controls to launch viewr.
- Camera RAW sensor data, wide-gamut and HDR output, and touch gestures remain
  outside this preview. A DNG or Sony ARW embedded baseline JPEG is a labelled
  preview only. Copying the on-screen image is included. Opening an image from
  clipboard pixels is not. JPEG is the supported rating-write format. Native
  language review of the bundled catalogs remains open.
- The v0.8 acceptance work remains open. This patch does not complete clean
  install on macOS, macOS update, full file-association acceptance, an
  original-M1 receipt, provenance beyond the existing release-workflow check,
  or the repeated 50,000-file rating probe.
