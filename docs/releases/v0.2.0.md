# viewr 0.2.0

The reliability architecture milestone. Every background operation now has one
bounded owner, stale work cannot mutate a newer selection, and a failure that
used to be silent is reported. Fit also stops enlarging a small image. No
feature scope was added, and the privacy boundary is unchanged.

This closes the **v0.2.0** exit criteria. The **v0.3.0** display-correctness
milestone is the next gate and remains open.

## Changed

- **A small image rests at actual size.** Fit scaled every image to fill the
  window, so a 64 by 64 source opened at 812 percent and a 320 by 240 fixture at
  217. An independent playtest put it plainly: honest as arithmetic and
  dishonest as looking. Fit now stops at one source pixel per physical display
  pixel, the same 100 percent the zoom readout reports, so a source smaller than
  the viewport is presented as the small image it is. A larger image still
  shrinks to fit, and enlarging a small one is something you ask for with zoom.

## Reliability

These landed across the v0.1.x line and are what the milestone certifies.

- **One bounded owner per background operation.** Image details, animation
  discovery, rating observation, folder scans, Save As, crop, over-limit display
  previews, every active folder-preview thumbnail, and every speculative
  neighbor decode each have a single event-loop-owned job and one non-cloneable
  completion endpoint. Replaced work cannot publish its result.
- **Stale work cannot mutate a newer selection.** Every result is checked
  against the exact path and generation that requested it, and cancellation is
  cooperative rather than abandoned.
- **A worker that dies is reported instead of waited on.** Each replace-latest
  decode queue closes when its last worker stops, including one that unwinds.
  Before this only the image preview queue noticed, so a worker lost on the
  foreground decode or current-image details queue left the operation busy
  forever with no error and nothing to report.
- **A malformed JPEG XL file cannot terminate the viewer.** Frame composition
  skips a channel clipped to zero area rather than borrowing a zero-width
  buffer and panicking. The exact input that found this is a permanent fuzz
  regression seed.
- **Launch failure is observable.** A missing windowing library, a missing
  session, or a graphics runtime that cannot present is a named message and a
  non-zero exit rather than an abort inside the dynamic loader, and `doctor`
  reports what is actually missing and how to install it.
- **The measured floor is honest.** Owned-logic coverage is 90.59 percent of
  lines under the CI contract, above the 85 percent floor, and the remaining
  whole-file exclusions are exactly the native integration surfaces: the winit
  event loop, the wgpu device, the worker sandbox and its process limits, and
  the two binary entry points.

## Install and verify

Download the archive for your platform or use the fixed-version installer
command in the [installation guide](../INSTALL.md). Every archive and installer
script has a SHA-256 sidecar and a GitHub build-provenance attestation. Archives
also contain a canonical per-file manifest.

The application itself has no network client. Installer scripts are separate,
foreground tools that contact only the official GitHub repository after you run
them. Updates are manual and explicit.

On Linux, a desktop session needs `libxkbcommon` plus either the X11 keyboard
and Xlib libraries or `libwayland-client`, and one usable graphics runtime:
`libEGL.so.1` for OpenGL, including Mesa software rendering, or `libvulkan.so.1`
with a driver installed behind it. `viewr doctor` reports exactly which of these
are missing and what to install.

## Preview limits

These portable archives are not Authenticode-signed on Windows or notarized on
macOS. Normal operating-system trust warnings may appear. Do not disable
platform security controls to force a launch.

Reaching this milestone does not shorten the remaining 1.0 gates: display
correctness, file coherence, format contracts, product quality, code signing and
notarization, and human Narrator, VoiceOver, and Orca acceptance. Release builds
still do not claim general recovery from an in-process thread panic. Optional
AVIF, HEIC, and RAW decoders are not enabled in these default archives.
