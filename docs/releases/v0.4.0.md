# viewr 0.4.0

The file-coherence preview. External replacement, rename, and deletion produce
deterministic visible states without blanking the last good frame or discarding
unsaved crop, heal, rotate, or flip. Open With uses a native user-mediated
chooser on Windows, macOS, and Linux.

This closes the **v0.4.0** exit criteria. The **v0.5.0** format-contract
milestone is the next gate and remains open. Multi-page TIFF/ICO and camera RAW
stay off this tag.

## File coherence

- **A session watcher observes the current file and folder.** It polls identity
  and directory membership without writing history or a catalog. Noisy events
  collapse to one visible change. Busy load, save, crop, heal, rating write, or
  curation work is never preempted.
- **Replacement reloads when that is safe.** If crop, including an applied crop,
  heal, rotate, and flip are idle, the current path is decoded again while the
  last good frame stays on screen. Otherwise a durable `F5` reminder stays with
  those pixels.
- **A missing path keeps the last good image.** The filename remains tied to the
  presented pixels, and a polite status says the selected path no longer names
  that file. A rename follows the same object in the folder list. A file that
  reappears after an atomic save is reloaded instead of being announced gone.
- **Open With is native on every shipping host.** Windows uses
  `SHOpenWithDialog`. macOS uses an application picker plus `NSWorkspace`.
  Linux uses the desktop-portal `OpenURI` chooser with `ask`. No path constructs
  a shell command or launches a default application silently. Source
  verification remains one generation-cancellable job.

## Install and verify

Download the archive for your platform or use the fixed-version installer
command in the [installation guide](../INSTALL.md). Every archive and installer
script has a SHA-256 sidecar and a GitHub build-provenance attestation. Archives
also contain a canonical per-file manifest.

The application itself has no network client. Installer scripts are separate,
foreground tools that contact only the official GitHub repository after you run
them. Updates are manual and explicit.

On Linux, a desktop session needs `libxkbcommon` plus either the X11 keyboard
and Xlib libraries or `libwayland-client`, and one usable graphics runtime:
`libEGL.so.1` for OpenGL, including Mesa software rendering, or `libvulkan.so.1`
with a driver installed behind it. `viewr doctor` reports exactly which of these
are missing and what to install. The Linux Open With chooser needs a session
bus and `xdg-desktop-portal`.

## Preview limits

These portable archives are not Authenticode-signed on Windows or notarized on
macOS. Normal operating-system trust warnings may appear. Do not disable
platform security controls to force a launch.

Reaching this milestone does not shorten the remaining 1.0 gates: format
contracts, product quality, code signing and notarization, and human Narrator,
VoiceOver, and Orca acceptance. Wide-gamut preservation and HDR presentation
stay off. Release builds still do not claim general recovery from an in-process
thread panic. Optional AVIF, HEIC, and RAW decoders are not enabled in these
default archives. Multi-page TIFF and ICO navigation remains the v0.5 work.
