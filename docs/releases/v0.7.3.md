# viewr 0.7.3

A focused patch over [v0.7.2](v0.7.2.md) for image navigation, viewing controls,
and interface polish. The viewer remains local-only and an unsigned preview.

## Changes

- Drag an image directly to pan. Compact open and closed hands distinguish idle
  and dragging states on Windows at the display's DPI. Hold Space to pan
  temporarily in Crop or Spot Heal. Pan limits keep part of the image reachable.
- Click the zoom percentage for Fit, Actual Size, Zoom In, and Zoom Out.
  Fullscreen starts at Fit and enlarges small images to the available viewport.
  Returning to the window refits there; Actual Size remains exact.
- Interface text prefers installed platform fonts with bundled glyph fallbacks.
  Console has softer phosphor-green text, quieter controls, thinner collage
  selection outlines, and smaller crop handles with unchanged drag targets.
- Theme and inspection backgrounds now match their intended colors instead of
  becoming too bright through a second sRGB conversion.
- File includes Exit or Quit viewr, with Ctrl+Q or Cmd+Q. These actions share the
  native window-close policy for pending writes.
- Unsupported formats keep the JPEG rating explanation in the Rating menu,
  leaving the viewing strip clear. JPEG rating state and errors remain visible.
- Fixed Windows folder scans that could reject an unchanged neighboring image
  after a legacy directory metadata probe. Direct-file sibling navigation is
  checked with a synthetic 319-image folder; changed and substituted sources
  remain rejected.
- Reduced unnecessary file access and repeated whole-file hashing on Windows
  network storage, preserved sibling scans through Trash, and made scan progress
  visible. These changes do not establish representative NAS acceptance.
- Updated existing patch-level dependencies and their locked packaging and
  license records. The application still has no HTTP or TLS client.

## Install and verify

Fixed-version installer commands and manual archive instructions are in the
[installation guide](../INSTALL.md). The four platform archives and installer
scripts have SHA-256 sidecars and GitHub build-provenance attestations. Each
archive contains a per-file manifest. The application has no account,
telemetry, analytics, activity history, normal-run logging, or update service.

## Preview limits

- Representative-hardware and Narrator, VoiceOver, and Orca acceptance rows
  remain uncollected. Automated checks do not prove usability on every host.
- Windows network-storage identity and navigation behavior have not been
  validated on a representative NAS or SMB share.
- Windows executables are not Authenticode-signed. macOS executables are not
  Developer ID signed or notarized. Normal operating-system trust warnings may
  appear; do not disable platform security controls to launch viewr.
- Camera RAW, wide-gamut and HDR output, touch gestures, and clipboard image
  pixel transfer remain outside this preview. JPEG is the supported rating-write
  format. Native language review of the bundled catalogs remains open.
- The v0.8 install, update, uninstall, association, and provenance acceptance
  work remains open. This patch does not claim completion of that milestone.
