# viewr 0.7.7

A focused patch over [v0.7.6](v0.7.6.md) for damaged JPEG files, PNG icons,
localized Image Information values, CLI help alignment, and a typed Save As
destination. The viewer remains local-only and an unsigned preview.

## Changes

- A JPEG that ends before its end-of-image marker, and whose decoded image
  finishes in the grey fill used for a missing scan, fails to open. The open
  reports that the file is damaged or incomplete. `viewr benchmark` skips that
  file with the same sentence. A complete JPEG is unchanged.
- ICO entries stored as PNG decode through the PNG decoder, including 24-bit
  RGB PNG entries. BMP icon entries stay on the ICO decoder.
- Image Information formats file size, aperture, focal length, and exposure
  with the active language's decimal separator. English uses a period.
  Spanish, French, and German use a comma. Sizes below 1 KiB stay whole byte
  counts.
- `viewr help` keeps each command and its description in aligned columns. On
  a narrower terminal the description wraps under that column.
- File > Save Path types a Save As destination when the native file chooser
  returns nothing. The field starts with the suggested JPEG name beside the
  open file. An existing destination still asks before replacement, and an
  invalid path reports Save failed. Cancelling a chooser shows that note and
  does not write a file. The typed destination stays in memory for the session.
- Reviewed dependency updates move crc32fast from 1.5.2 to 1.5.3 and roxmltree
  from 0.21.1 to 0.21.2.

## Install and verify

Fixed-version installer commands and manual verification are in the
[installation guide](../INSTALL.md). All four platform archives and installer
scripts have SHA-256 sidecars and GitHub build-provenance attestations. Each
archive contains a per-file manifest. The application has no account,
telemetry, analytics, activity history, normal-run logging, or update service.

## Preview limits

- Representative-hardware and Narrator, VoiceOver, and Orca acceptance rows
  remain uncollected. Automated checks do not prove usability on every host.
- Windows network-storage behavior has not been validated on a representative
  NAS or SMB share. The 50,000-image rating scan, OS contrast acceptance, and
  installer recovery matrix remain separate open evidence requirements.
- Windows executables are not Authenticode-signed. macOS executables are not
  Developer ID signed or notarized. Normal operating-system trust warnings may
  appear; do not disable platform security controls to launch viewr.
- Camera RAW, wide-gamut and HDR output, and touch gestures remain outside
  this preview. Copying the on-screen image is included. Opening an image from
  clipboard pixels is not. JPEG is the supported rating-write format. Native
  language review of the bundled catalogs remains open.
- The v0.8 acceptance work remains open. This patch does not complete clean
  install on macOS, macOS update, full file-association acceptance, provenance
  beyond the existing release-workflow check, or the repeated 50,000-file
  rating probe.
